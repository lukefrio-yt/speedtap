# Speed Tap

Fast-paced local multiplayer (2–4 players) and solo reaction tapping web game built with pure HTML, CSS, and JavaScript.

## Features (English)

- **Game Modes:** Solo Training (1 player) and Local Multiplayer Duels (2–4 players on one device via touch or keyboard).
- **Accounts & Economy:** Local player profiles (`localStorage`), coins, and boosts.
- **Cosmetic Shop:** Unlockable avatar frames, custom fonts, and backgrounds.
- **Hall of Fame & History:** Tracks match results and best scores locally.

## Usage

1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser (no build step required).
3. Create or sign in to a local profile, choose a mode, and start tapping!

# Speed Tap (Česky)

Rychlá webová postřehová hra pro lokální multiplayer (2–4 hráči) i sólo trénink, vytvořená v čistém HTML, CSS a JavaScriptu.

## Funkce

- **Herní režimy:** Sólo trénink (1 hráč) a lokální duely pro 2–4 hráče na jednom zařízení (dotykem nebo klávesnicí).
- **Účty a ekonomika:** Lokální hráčské profily (`localStorage`), mince a boosty.
- **Obchod s kosmetikou:** Odemknutelné rámečky, fonty a pozadí.
- **Síň slávy a historie:** Lokální záznam odehraných her a nejlepších výsledků.

## Jak hrát

1. Naklonujte nebo stáhněte repozitář.
2. Otevřete `index.html` přímo v libovolném moderním prohlížeči (bez nutnosti instalace či sestavení).
3. Vytvořte si lokální profil, vyberte režim a začněte klikat!
